# Kerala Jyothisham Rules & App Standards
- Always use Chitra Paksha (Lahiri) Ayanamsa for sidereal longitudes.
- Enforce Sunrise-to-Sunrise Vara boundaries and Kerala 3/5ths daytime (Aparahna) Kollavarsham Sankramam rules.
- Keep the app 100% client-side in a single HTML file with zero external dependencies.
- Escape all user-entered profile text before DOM insertion.
